# Project Overview

This repository contains a simple JavaScript implementation for a word‑guessing game. The main logic resides in `script.js`, which handles user input, checks answers against a predefined answer array, and updates the UI accordingly.

## Files

- **script.js** – Core game logic that captures keyboard and button events, validates user guesses, and provides visual feedback.

## How to Run

1. Open the HTML file that includes `script.js` in a web browser.
2. Type your guesses into the provided input fields or press **Enter** to submit.
3. The script will compare your input against the answer `"t a t t y"` and highlight correct, partial, or incorrect letters.

## Development

- Ensure you have a modern browser that supports ES6 features.
- Feel free to modify the `ANSWER` array in `script.js` to change the target word.
